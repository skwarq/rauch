# Local research inputs

This directory is reserved for local, non-published reverse-engineering inputs.
The repository's `.gitignore` excludes proprietary and generated artifacts,
including:

- RAUCH APK files and JADX output under `apk/`;
- packet captures under `network/`;
- third-party DLL, EXE, and PEX files.

The protocol documentation records the relevant findings without requiring
these files. Anyone reproducing the analysis must supply legally obtained input
files locally.
